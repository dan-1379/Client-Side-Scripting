## Run Locally
Choose the folder where you want the project
```bash
  cd path/to/your/folder
```

Clone the repository
```bash
  git clone https://github.com/dan-1379/Client-Side-Scripting.git
```

Open the folder
```bash
  cd Client-Side-Scripting
```

Open the project in VSCode
